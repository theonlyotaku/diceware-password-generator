# diceware-password-generator

simple cryptographically secure diceware password generator written in python using the secrets module

process: 5 dice rolls gives a combination of five digits, each ranging from 1-6, and each combination gives the corresponding word from the [word list](https://www.eff.org/files/2016/07/18/eff_large_wordlist.txt). the number of words depends on the length of the password chosen by the user.
